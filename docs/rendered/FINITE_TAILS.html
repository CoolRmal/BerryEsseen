Certified Gaussian tails in all finite cells

For n≥N>0n\ge N>0n≥N>0, c>0c>0c>0, and τ>0\tau>0τ>0, the proved Gaussian tail estimate is

Set q=c2Nτ2q=c^2N\tau^2q=c2Nτ2. In every saved cell this is a positive rational number. The argument of the exponential is therefore the exact rational −q/2-q/2−q/2. To certify a rational upper bound UUU, the checker verifies:

  1. The sample-size floor, cutoff, and split are positive.
  2. The exponential seed's input interval contains −q/2-q/2−q/2.
  3. Its certified output upper endpoint EEE satisfies E/(πlowq)≤UE/(\pi_{\rm low}q)\le UE/(πlow​q)≤U, where πlow=13493037704/232≤π\pi_{\rm low}=13493037704/2^{32}\le\piπlow​=13493037704/232≤π.

Monotonicity of the exponential and division by positive denominators proves the real tail bound. The seed is checked by rational Taylor arithmetic and repeated squaring, using the previously proved exponential certificate rules. All 174 saved cells have checked tail certificates. Their statements apply to every sample size above the recorded floor, rather than only the particular sample size used to compute the table.

The generic proof is Numerics/FiniteTailCertificate.lean; the complete collection is Certificates/FiniteTails/Complete.lean. Regenerate with python3 scripts/import_finite_tails.py and check with lake build BerryEsseen.Certificates.FiniteTails.Complete.

These tail bounds are joined with the other three smoothing terms in the complete finite cells. The universal upper theorem and the ordinary Lean build have passed; the separate comparator check is pending.
